# KojoTech

**Building Digital Solutions.**

Official website and platform for KojoTech — a technology brand building modern websites, web applications, business management systems, e-commerce solutions, and custom digital products.

Founded by **Francis Kojo Haizel** — Full-Stack Developer | WordPress Developer | AI & Technology Enthusiast.

## Stack

- **Frontend:** React + Vite + Tailwind CSS + Framer Motion
- **Backend:** Node.js + Express + MongoDB + Mongoose
- **AI Assistant:** KojoTech Bolt (OpenRouter primary + Gemini fallback)
- **Deployment:** Vercel (frontend) + Dokploy (backend) + MongoDB Atlas + Cloudflare
